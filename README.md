# Sukh's BMW Web App

A modern, full-stack BMW car configurator and showcase application.

## Features

- 🚗 Browse BMW models
- 🎨 Customize and configure vehicles
- 💰 Real-time pricing
- 📊 Inventory management
- 🔐 User authentication (coming soon)
- 📱 Responsive design

## Tech Stack

### Frontend
- React 18+
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Getting Started

### Prerequisites
- Node.js (v16+)
- MongoDB
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/sukhsahota180-star/sukh-bmw-web-app.git
cd sukh-bmw-web-app
```

2. Install frontend dependencies
```bash
cd client
npm install
```

3. Install backend dependencies
```bash
cd ../server
npm install
```

### Running the App

1. Start MongoDB
2. Start backend: `npm run dev` (from server/)
3. Start frontend: `npm run dev` (from client/)
4. Open http://localhost:5173
